¿Por qué es mala práctica usar SELECT * en producción? Mencioná al menos dos razones concretas (rendimiento, mantenibilidad, seguridad).
Cuando utilizamos el comando SELECT *, nos trae información de toda la tabla. Es una forma de empezar a familiarizarnos con los datos, ver qué columnas existen y entender de qué se trata la estructura. Pero en producción no conviene usarlo por dos motivos principales: Rendimiento: trae columnas que no necesitamos y eso hace que la consulta sea más pesada y lenta. Mantenibilidad y seguridad: si la tabla cambia, tu consulta puede devolver cosas inesperadas, y además puede mostrar datos sensibles sin querer.
¿Por qué son importantes los alias para un interesado no técnico? Explique con un ejemplo concreto cómo un alias transforma total_amount en algo que cualquier persona del área de finanzas puede interpretar directamente. Los alias son importantes para alguien que no es técnico porque básicamente les traducen el nombre de las columnas a algo que entienden rápido, sin tener que saber inglés ni cómo está armada la base de datos. Ellos miran la información, no el nombre técnico.
